# frameshell · shell

The frameshell desktop: Quickshell (bar, launcher, lockscreen, notifications, control center, OSD, screenshots, wallpaper app), the Hyprland Lua config, the wallpaper helper, the login screen (greetd), the boot splash and the GTK theme. Always installed.

Part of [frameshell](https://github.com/frame-shell); install it with the `frame` command:

```bash
frame add shell
```

Files in the package folders are linked into your home with GNU Stow; files with colors come
from `templates/` and are written by `frame theme` in the active theme. Ideas and bugs:
[the board](https://github.com/orgs/frame-shell/projects/1).
